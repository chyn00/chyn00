## 안녕하세요, 백엔드 개발자 Ted입니다.

대규모 운영 환경에서 기존 시스템이 만들어진 이유와 변경 영향도를 먼저 이해하고, 안정성을 지키며 점진적으로 개선합니다.

리테일 재고·인증 시스템을 개발해 왔으며, 현재는 0→1로 서비스를 구성하며 현장의 수기 업무를 PC·모바일 웹 서비스로 전환해 직접 배포·운영하고 있습니다. 역할별 전문성이 축적되는 AI 에이전트 하네스도 설계했습니다.

아이디어를 제안에 두지 않고, 주어진 자원으로 구현·배포·관찰·개선해 실제로 작동하는 결과까지 만드는 것을 중요하게 생각합니다.
